# 컴퓨터 성능 단위
> 처리량(throughput) 클수록 좋다
> 응답량(response time) 짧을수록 좋다
1. MIPS
	- 5 IPS - 5개명령 / 1s
	- 5000 IPS - 5 KIPS
	- 5000000 IPS - 5 MIPS
2. FLOPS
	- 5 Floating point Operation / 1s
	- 5개 실수연산 / 1초
	- 5000 FLOPS > 5KFLOPS
	- 5000000 FLOPS > 5MFLOPS
3. **클록**
	- 클록 주파수: 1초에 실행되는 마이크로오퍼레이션
	- 클록 주기: 하나의 마이크로오퍼레이션이 실행돠는 시간으로 단위는 초(sec)이다
	- CPI(Clock Per Instruction): 하나의 명령어를 실행하는 데 필요한 클록 주기 수
	- **프로그램 수행시간** = **명령어 개수** `*` **평균CPI**(명령 1개 실행시간`*`CPI)`*` **클록 주기**

# 컴퓨터 기억용량 단위
| 단위 | 이름 | 2의 거듭제곱 | 이전 단위와 관계 |
|---|---|---|---|
| bit | 비트 | 0 또는 1 | 최소 정보 단위 |
| B | 바이트 | 8bit | 1B = 8bit |
| KB | 킬로바이트 | 2¹⁰ B | 1KB = 1024B |
| MB | 메가바이트 | 2²⁰ B | 1MB = 1024KB |
| GB | 기가바이트 | 2³⁰ B | 1GB = 1024MB |
| TB | 테라바이트 | 2⁴⁰ B | 1TB = 1024GB |
| PB | 페타바이트 | 2⁵⁰ B | 1PB = 1024TB |
| EB | 엑사바이트 | 2⁶⁰ B | 1EB = 1024PB |
| ZB | 제타바이트 | 2⁷⁰ B | 1ZB = 1024EB |
| YB | 요타바이트 | 2⁸⁰ B | 1YB = 1024ZB |
