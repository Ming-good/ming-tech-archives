# 하드웨어
1. 중앙처리장치(CPU)
	- 제어장치: 명령 수행(순서제어)
	- 연산장치: 데이터 인출 및 연산`(산술 > sift > 관계 > bit논리 > 논리)`
>>>> CPU -> 주기억장치 -> 보조기억장치 방향으로만 쓰기가 가능하다.
2. 기억장치
	- 주기억장치
		- ROM - 비휘발성
		- RAM  - 휘발성, 읽기·쓰기 가능
	- 보조기억
		- SSD - 반도체(전기)
		- HDD - 디스크드라이브
			- 기계식
			- 발열
			- 느림
3. 입출력장치
	- 입력: 키보드, 마우스
	- 출력: 모니터, 프린터
