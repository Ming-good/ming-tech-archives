# 하드웨어
1. 중앙처리장치(CPU)
	- 제어장치: 명령 수행(순서제어)
		- 상세: 명령 인출 -> 해독 -> 제어신호 발생
	- 연산장치: 데이터 인출 및 연산`(산술 > sift > 관계 > bit논리 > 논리)`
		- 상세: 데이터 인출 -> 실행
	- 레지스터
	- 시스템버스
>>>> CPU -> 주기억장치 -> 보조기억장치 방향으로만 쓰기가 가능하다.
2. 기억장치
	- 주기억장치: 명령집함 + 데이터(2진수형태 - 프로그램 내장 방식)
		- ROM - 비휘발성
		- RAM  - 휘발성, 읽기·쓰기 가능
	- 보조기억
		- SSD - 반도체(전기)
		- HDD - 디스크드라이브
			- 기계식
			- 발열
			- 느림
3. 입출력장치
	- 입력: 키보드, 마우스(외부 -> 내부)
	- 출력: 모니터, 프린터(내부 -> 외부)

# 소프트웨어
1. 시스템 스프트웨어 - OS, 언어번역(컴파일러, 인터프리터, 어셈블러)
2. 응용 스프트웨어 - 한글, 엑셀 등등

| 고급언어 -> 저급언어 | 컴파일러(C, Fortran, GoBol)   | 인터프리터     | 어셈블러                            |
| ------------ | ------------------------- | --------- | ------------------------------- |
| 번역 단위        | 파일                        | 문장        | 저급언어 -> 기계어<br>`[어셈블리어] -> 2진수` |
| 번역 속도        | 상대적으로 느리다                 | 상대적으로 빠르다 |                                 |
| 실행 속도        | 상대적으로 빠르다                 | 상대적으로 느리다 |                                 |
| 목적 프로그램      | 생성한다.                     | 생성하지 않는다. |                                 |
| 메모리 할당       | 할당받는다.<br>(반복문이 많을 떄 효율적) | 사용하지 않는다. |                                 |
