### 표준 BCD 코드
- 6bit - $2^6$개
- 대문자, 소문자를 구별하지 못한다.
- Zone: 2bit, Digt: 4bit
### ASCII
- 7bit - $2^7$개 + 전송제어문자
- Zone: 3bit, Dgit: 4bit
### EBCDIC
- 8bit - $2^8$개
- Zone: 4bit, Dgit: 4bit
### Uni Code
- 16bit - $2^{16}$ = 65536개
- 자릿값이 있는 코드(가중치 코드) 사용
- Gray는 통신에서 많이 사용되며 최대한 비트 입력간에 에러발생을 줄이기 위해 한 비트씩만 바뀌도록 설계됨
- 패리티 비트: 1개의 패리티 비트를 데이터에 추가하여 사용된다.
	- 짝수 패리티: 1000001**1**
	- 홀수 패리티: 1000001**0**
	- 이중 패리티 방식

# 수치형 데이터 표준
### 10진 연산
1. 연팩 연산
	- 입출력 데이터로 사용 가능
	- 연산용 데이터 불가
2. 팩 연산
	- 입출력 데이터로 불가
	- 연산용 데이터로 가능
### 2진 고정소수점 연산 
- 8비트기준

| 표현 방식     | +12         | -12         | 음수 변환 방법      |
| --------- | ----------- | ----------- | ------------- |
| 부호와 절댓값   | `0000 1100` | `1000 1100` | 부호 비트만 1로 변경  |
| 부호와 1의 보수 | `0000 1100` | `1111 0011` | 모든 비트 반전      |
| 부호와 2의 보수 | `0000 1100` | `1111 0100` | 모든 비트 반전 후 +1 |
- 4비트 기준
	- 부호와 절댓값 / 1의 보수: -7 ~ +7
	- 2의 보수: -8 ~ +7
	- 2의 보수만 음수 표현 범위가 1개 더 넓음
	- 부호와 절댓값 및 1의 보수는 +0과 -0이 존재
	- 2의 보수는 0이 하나만 존재

| 10진수 | 부호와 절댓값 | 1의 보수 | 2의 보수 |
|---|---|---|---|
| +7 | 0111 | 0111 | 0111 |
| +6 | 0110 | 0110 | 0110 |
| +5 | 0101 | 0101 | 0101 |
| +4 | 0100 | 0100 | 0100 |
| +3 | 0011 | 0011 | 0011 |
| +2 | 0010 | 0010 | 0010 |
| +1 | 0001 | 0001 | 0001 |
| +0 | 0000 | 0000 | 0000 |
| -0 | 1000 | 1111 | 없음 |
| -1 | 1001 | 1110 | 1111 |
| -2 | 1010 | 1101 | 1110 |
| -3 | 1011 | 1100 | 1101 |
| -4 | 1100 | 1011 | 1100 |
| -5 | 1101 | 1010 | 1011 |
| -6 | 1110 | 1001 | 1010 |
| -7 | 1111 | 1000 | 1001 |
| -8 | 표현 불가 | 표현 불가 | 1000 |
