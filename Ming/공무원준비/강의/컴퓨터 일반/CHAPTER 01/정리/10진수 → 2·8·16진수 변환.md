## 1. 변환 원칙

|구분|계산 방법|읽는 순서|
|---|---|---|
|정수 부분|변환할 진수로 계속 나누기|나머지를 아래 → 위|
|소수 부분|변환할 진수를 계속 곱하기|정수 부분을 위 → 아래|
- 2진수: 2로 나누거나 곱하기
- 8진수: 8로 나누거나 곱하기
- 16진수: 16으로 나누거나 곱하기 (10~15는 A~F)

## 2. 정수 변환 (42)
### ① 10진수 → 2진수
```
42 ÷ 2 = 21 ... 0
21 ÷ 2 = 10 ... 1
10 ÷ 2 =  5 ... 0
 5 ÷ 2 =  2 ... 1
 2 ÷ 2 =  1 ... 0
 1 ÷ 2 =  0 ... 1
```
**결과: (42)₁₀ = (101010)₂**

### ② 10진수 → 8진수
```
42 ÷ 8 = 5 ... 2
 5 ÷ 8 = 0 ... 5
```
**결과: (42)₁₀ = (52)₈**

### ③ 10진수 → 16진수
```
42 ÷ 16 = 2 ... 10(A)
 2 ÷ 16 = 0 ... 2
```
**결과: (42)₁₀ = (2A)₁₆**

## 3. 소수 변환 (0.625)
소수 부분에 변환할 진수를 곱하고, 결과의 **정수 부분만 순서대로 기록**한다. 남은 소수 부분이 0이 될 때까지 반복한다.

### ① 10진수 → 2진수
```
0.625 × 2 = 1.25 → 1
0.25  × 2 = 0.5  → 0
0.5   × 2 = 1.0  → 1
```
**결과: (0.625)₁₀ = (0.101)₂**

### ② 10진수 → 8진수
```
0.625 × 8 = 5.0 → 5
```
**결과: (0.625)₁₀ = (0.5)₈**

### ③ 10진수 → 16진수
```
0.625 × 16 = 10.0 → A
```
**결과: (0.625)₁₀ = (0.A)₁₆**

## 4. 핵심 암기

> **정수는 나누고 역순, 소수는 곱하고 정순.**
- 정수와 소수가 함께 있으면 각각 변환한 뒤 소수점으로 연결한다.
- 소수 부분이 0이 되지 않으면 무한소수가 될 수 있으므로 문제에서 요구하는 자릿수와 반올림 조건을 따른다.

**최종 예시**
- (42.625)₁₀ = (101010.101)₂
- (42.625)₁₀ = (52.5)₈
- (42.625)₁₀ = (2A.A)₁₆
