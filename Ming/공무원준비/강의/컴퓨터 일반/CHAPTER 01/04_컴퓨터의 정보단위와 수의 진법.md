# 컴퓨터 정보표현 단위
1. 비트(bit)
	- 0 또는 1 nBit -> $2^n$개 정보 표현 가능 
2. 니블(nibble)
	- 4Bit를 묶음
	- 16진수 1글자
3. 바이트(Byte)
	- 8Bit 단위
	- 저장용량 단위
4. 워드(Word)
	- 중앙처리장치가 주기업장치에 접근할 때 한 번에 읽을 수 있는 단위로 주기억장치 한 번지의 크기를 의미

# 보수
1. 보수는 두 개 뿐이다
	- 예를들어 10진수의 보수는 10,9
	- 2진수의 보수는 2,1
2. 347의 9의 보수 구하기 -> 652(세자리의 가장 큰 숫자 999가 되려면)
	- -347를 이용하겠다라는 의미
	- 더하기 대신 빼기를 하겠다는 의미
	- EX) 9의 보수
		- 758 - 347 = 411
		- 758 + 652 = 1410 => (1)410 + 1 = 411
3. 347의 10의 보수 구하기 -> 653
4. 0011의 1의 보수 -> 1100
5. 0011의 2의 보수 -> 1101
> 9의 보수와 2의 보수에 결국 1을 더하면 구해진다.
