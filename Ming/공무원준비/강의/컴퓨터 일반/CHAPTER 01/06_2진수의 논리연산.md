# 산술적 이동
### 산술 shift
- +15 - 왼쪽 << n  = n bit 왼쪽 Shift
	- n bit 이동 = +15 `*` $2^n$ 
- +15 - 오른쪽 >> n  = n bit 오른쪽 Shift
	- n bit 이동 = +15 / $2^n$
	- 소수점 이하는 값을 **절삭**한다.
		- 부호 2의 보수 = -15 >> 1 = -8
		- 부호 1의 보수 = -15 >> 1 = -7

|표현 방식|왼쪽 이동 (×2)|오른쪽 이동 (÷2)|
|---|---|---|
|부호와 절댓값|0 삽입|0 삽입|
|1의 보수|1 삽입|1 삽입|
|2의 보수|0 삽입|1 삽입|
> 실수에서는 Shift연산이 안된다. 정수에서만 가능하다
