# 컴퓨터 성능 단위
> 처리량(throughput) 클수록 좋다
> 응답량(response time) 짧을수록 좋다
1. MIPS
	- 5 IPS - 5개명령 / 1s
	- 5000 IPS - 5 KIPS
	- 5000000 IPS - 5 MIPS
2. FLOPS
	- 5 Floating point Operation / 1s
	- 5개 실수연산 / 1초
	- 5000 FLOPS > 5KFLOPS
	- 5000000 FLOPS > 5MFLOPS
3. **클록**
	- 클록 주파수: 1초에 실행되는 마이크로오퍼레이션
	- 클록 주기: 하나의 마이크로오퍼레이션이 실행돠는 시간으로 단위는 초(sec)이다
	- CPI(Clock Per Instruction): 하나의 명령어를 실행하는 데 필요한 클록 주기 수
	- **프로그램 수행시간** = **명령어 개수** `*` **평균CPI**(명령 1개 실행시간`*`CPI)`*` **클록 주기**

# 컴퓨터 기억용량 단위
| 단위 | 이름 | 2의 거듭제곱 | 이전 단위와 관계 |
|---|---|---|---|
| bit | 비트 | 0 또는 1 | 최소 정보 단위 |
| B | 바이트 | 8bit | 1B = 8bit |
| KB | 킬로바이트 | 2¹⁰ B | 1KB = 1024B |
| MB | 메가바이트 | 2²⁰ B | 1MB = 1024KB |
| GB | 기가바이트 | 2³⁰ B | 1GB = 1024MB |
| TB | 테라바이트 | 2⁴⁰ B | 1TB = 1024GB |
| PB | 페타바이트 | 2⁵⁰ B | 1PB = 1024TB |
| EB | 엑사바이트 | 2⁶⁰ B | 1EB = 1024PB |
| ZB | 제타바이트 | 2⁷⁰ B | 1ZB = 1024EB |
| YB | 요타바이트 | 2⁸⁰ B | 1YB = 1024ZB |
# 정보처리 시스템의 분류
1. 일괄처리
	- 입력(일정기간,일정량) 모아서 한꺼번에 처리
	- 입출력을하는 동안 CPU는 일을 하지 않는다(**동시 실행 X**)
	>	EX) 등수포함 성적, 월급, 세금계산
2. 다중프로그래밍
	- CPU의 처리량을 극대화
	- 주기억장치 1개 - 프로그램 여러개 적재
	- CPU가 프로그램 여러개 번갈아 수행
3. 실시간
	- 입력 즉시 처리
4. 시분할
	- CPU 시간 분할(각 사용자는 **마치** 혼자 CPU를 점유하는 것 같이 느낀다.)
5. 다중처리
	- CPU가 여러개, 1개의 기억장치에 여러 개의 프로그램이 존재
	- **강결합(=밀결합)**
![[Pasted image 20261023203257.png]]
6. 분산처리(**네트워크**)
	- 여러 개의 컴퓨터에 분산시킨 후 통신망을 통해 상호간 교환, 처리
	- **약결합**
	- EX) 
		- 클러스터링(LAN) - 폐쇄적 
		- 그리드(인터넷)
		- 클라우드 컴퓨팅(인터넷 + 가상화 기술)
			- 가상화 기술
				- IaaS - 가상서버 스토리지
				- PaaS - 개발환경
				- SaaS - 응용소프트웨어
