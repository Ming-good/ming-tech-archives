# 암호
> 평문을 해독 불가능한 형태로 변형하거나 암호화된 통신문을 해독 가능한 형태로 변환하기 위한 원리
1.  대칭키 개수
	- n명이 있을때 최대 n(n-1)/2개
2. 공개키 개수
	- n명이 있을 때 최대 2n개\

# 암호의 역사
1. 스테가노그래피 
	- **정보은닉** 효과
	- 원문에 숨기고자하는 내용이 포함된다
	- 디지털 워터마킹 = 디지털 콘텐츠 + 저작권자 정보
	- 디지털 핑거프린팅 = 디지털 워터마킹 + 구매자 정보(불법복제 방지)
2. 고대 암호의 특징
	- 고대 암호는 전부 **대칭키**이다
	- 치환 = 대체 = 대치
	- 전치는 치환 안에 들어가는 개념
	- ![[Pasted image 20261026182102.png]]
3. 고대암호
	1. Scytale 암호
		-  봉의 길이가 대칭키

	2. 덧셈 암호
		- 시저 암호(ROT3) = 이동 암호
		- ROT13은 시저 암호의 일종으로 영어 알파벳을 13글자씩 밀어서 만든다.

	- 기계식 다중치환 암호
	- 회전자의 위치가 변하면서 치환 규칙이 변경됨
	- 동일한 평문 문자도 회전자 위치에 따라 다른 암호문으로 변환 가능
	- 대표적인 암호 기계: 에니그마(Enigma)
