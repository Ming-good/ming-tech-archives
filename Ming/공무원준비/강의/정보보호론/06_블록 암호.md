# 블록 암호 모드
### ECB 모드  - 전자코드북
- 패딩있음
- 취약점: 평문블록이 똑같으면 똑같은 암호블록 나옴
- 암호와, 복호화 모두 병렬화 O
- 에러 전파 없음
### CBC 모드(중요)
- 엄호와, 복호화 병렬화 X 
	- <암호문블록1>로 XOR하기에
-  기밀성을 챙기려면 **키**이다! **IV값은 무결성**이다!
- IV값은 반드시 비밀일 필요는 없다 
- 에러전파 - 평문 블록 i번째 에러 -> 마지막 암호문 블럭까지  
	-  <암호문블록1>로 XOR하기에
	- 암호문블록 i번째 에러 -> 대응하는 평문블럭 i, i+1 에러 전파
	- 평문블록 i번째 에러 -> 마지막 암호문 블럭까지 에러 전파
### CFB 모드
- 패딩이 필요없다
- 암호화 평블 i 에러 -> 마지막 암호문블럭까지
- 복호화 암블 i 에러 -> 대응하는 평블 i, i+1 에러 전파
### OFB 모드
- 완벽한 병렬X
- IV를 암호화해서 사용함으로 독립적이다
- 블럭암호 기반 스트림 암호다
### CTR 모드(중요)
- 완벽한 병렬
- 에러전파 없음
- CTR의 초기값은 암호화 때마다 다른 값을 기초로 해서 만든다\

>ECB·CBC는 블록 방식, CFB·OFB·CTR은 스트림 방식으로 동작하지만, 다섯 가지 모두 블록 암호의 운영 모드다


---

| 운용 모드 | 병렬/직렬                    | 암호화 입력               | 패딩 필요 여부 | 암·복호화 구조  | 시프트 레지스터 사용 여부 |
| ----- | ------------------------ | -------------------- | -------- | --------- | -------------- |
| ECB   | 병렬                       | 평문 블록                | 필요       | E/D = 다르다 | X              |
| CBC   | 직렬                       | IV + 평블<br>이전평블 + 평블 | 필요       | E/D = 다르다 | X(이전 단계를 저장)   |
| CFB   | 직렬 - 수신측<br>(사전준비)       | 이전 암호문(최초 IV)        | 불필요      | E/E = 같다  | O              |
| OFB   | 직렬 - 송수신측<br>(사전 준비시 병렬) | 이전 암호화 출력(최초 IV)     | 불필요      | E/E = 같다  | O              |
| CTR   | 병렬                       | CTR + 0              | 불필요      | E/E = 같다  | X              |
