# 대칭키
1. 특징
	- 알고리즘 - 전치, 치환, XOR
	- 송신, 전송, 수신 암호키는 동일
	- 평문의 길이 = 암호문의 길이
2. 비트열 XOR - 스트림암호
	- 비트논리 - 배타적 논리합
	- **일회용 패드(one-time pad)**
		- 전사 공격에도 해독할 수 없다(키의 경우의스 + 부정)
		- EX) OTP(One Time Pad)
			- One Time Password는 다른것
3. DES(Data Encryption Standard)
- ![[Pasted image 20261028203557.png]]
- S-Box 치환 방법
	- S-Box는 DES의 **안전성**을 책임짐
	- 6bit 입력 값을 치환표를 통해 4bit로 치환 -> 8개의 S-Box를 사용
	- EX) **1**0001**1** => 3행 1열
		- 11(2) = 3(10) = 행번호
		- 0001(2) = 1(10) = 열번호
	- DES 취약키는 4개 존재
		- 취약키를 이용하여 블록을 암호화하고 다음 동일한 취약키로 결과를 암호화하면 원래의 블록을 얻음
> 용어: 전사공격, 무차별대입 공격, brute-force공격, 전수공격

# 이중 DES
- 특징
	- 키 길이  = 56 * 2 = 112bit
	- 라운드 수 = 16:2 = 32라운드
- 취약점
	- 암호화/복호화시 **중간일치공격**으로 실제 키길이는 $2^{112}$ 가 아닌 $2^{57}$ 으로 밝혀짐
- 암호화 과정
	1. 평문  
	2. ->`DES암호화 * k1` 
	3. -> 중간암호문 
	4. -> `DES암호화 * k2` 
	5. -> 최종 암호문
- 복호화 과정
	1. 암호문
	2. -> `DES암호화 * k2` 
	3. -> 중간암호문
	4. -> `DES암호화 * k1` 
	5. 평문
