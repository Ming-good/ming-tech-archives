# 인터넷 보안 요구사항
1. 시스템 보안
2. 클라이언트 인증
3. 서버 인증
4. 전송되는 데이터의 인증, 기밀성, 무결성 보장
5. 접근제어
# 네트워크의 종류
1. LAN: 근거리통신망(사설망) - 보안성 높음
2. MAN: 거대도시 통신망
3. WAN: 원거리 통신망(공중망) - 보안성 매우 낮다
# 표준화된 프로토콜 제정하는 기관
1. ISO/IEC(국제표준화기구)
	- 27001: 정보보호
	- 27700: 개인정보보호
2. ANSI(미국 국내 표준) 
	- FDDI(이중링, 광케이블, 멀티토큰)
	- ASCii: 7bit문자
3. EIA(미국전자제품 전송 표준)
	- RS-232C
4. IEEE(LAN의 접속 규격과 처리애 대한 표준)
5. ITU-T(국제 통신 연합)
	- X.509: 인증서 형식
6. IAB(인터넷에 요구되는 다양한 표준)
	- TCP/IP
	- SNMP
	- RFC
# 서비스와 메커니즘
1. 데이터 기밀성: 암호화, 트래픽 패딩, 라우팅 제어
2. 데이터 무결성: 체크섬(해시값)
3. 인증
	- 연결형: 송신자와 수신자 인증
	- 비연결형: 데이터의 출처를 인증
4. 부인봉쇄: 공개키(전자서명), 공증
5. 접근제어
> 기밀성이 강력하면 무결성은 보장이 된다.
