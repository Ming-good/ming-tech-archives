## 정보보호 3대 목표
1. 기밀성 - 유출
2. 무결성 - 훼손, 변조
3. 가용성 

# 정보보안 기본 목표
### 3대 목표(권한있는 자)
1. 기밀성(confidentiality)
	- 읽기와 접근이 가능해야 된다.
	- 대책: 접근제어 + 암호화
2. 무결성(Integrity)
	- 정확성,완전성,최신성
	- 적법한 절처를 통해 쓰기 가능해야 한다.
	- 대책: 
		- 물리적 접근제어 
		- + 접근제어 권한검사 
		- + 해시함수, 메시지인증코드(대칭키), 전자서명(공개키-개인키)
3. 가용성(Availobility)
	- 원할 때(적시성) 사용 가능해야 된다.
	- 대책: 서버 이중화, 백업 + 안전한 시스템 설계
### 그 외 목표
1. 인증성(Authentication)
	- 실체확인 = 사용자/컴퓨터, 메시지 출처인증
	- 네트워크가 발전하여 중요해짐
2. 책임 추적성 - 문제 발생 시 책임 질 사람,행위추적
	- 로그, 포렌식 필요(보관기간 3년)
3. 신뢰성
### 가용성과 보안성 관계
1. 가용성과 보안성(**기밀,무결**)의 관계는 반비례한다.

# 정보보안 침해 유형
1. 기밀성 위협
	- 메시지내용 공개
		- 대응: 암호화
	- 트래픽 분석
2. 무결성 위협
	- 변경
	- 신분위장: 실제 인증성 위협이나 넓은 범위에서 무결성 위협이된다.
	- 재전송: 신분위장이 포함됨
		- 대응: 타임스탬프, 순서번호, nonce(비포)
	- 부인: 대칭키만으로는 부인 방지가 안됨 => 환경이 같기 떄문 => **사용하는 키**가 서로 달라야함.
3. 가용성 위협
	- 서비스 거부(DOS) - 플러딩 공격
4. 소극적 공격과 적극적 공격

| 구분         | 소극적 공격 (Passive Attack)     | 적극적 공격 (Active Attack)      |
| ---------- | --------------------------- | --------------------------- |
| **공격 유형**  | 스니핑, 스누핑, 메시지 내용 공개, 트래픽 분석 | 변조, 신분 위장, 재전송, 서비스 거부(DoS) |
| **위협 요소**  | 기밀성                         | 무결성, 가용성                    |
| **탐지 가능성** | 탐지 어려움                      | 상대적으로 탐지 용이                 |
| **예방 가능성** | 예방 중심의 대응 가능                | 완벽한 예방 어려움                  |
| **대응 전략**  | 암호화 등 사전 예방에 중점             | 탐지 및 빠른 복구에 중점              |
