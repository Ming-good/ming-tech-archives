## 1. 준동사
#### TO 부정사
1. (not) + to 부정사
	- to + **동사원형** → to부정사  
	- to + **명사** / **동명사** → 전치사
```
I want to eat. → to부정사  
I went to school. → `to`는 전치사
```

2. to부정사의 부정
	- **not + to + 동사원형**
```
I decided not to go.
```

3. to부정사의 수동태
	- to + 동사원형 → 능동
	- to be + p.p. → 수동
```
challenges are guaranteed to be solved
```
---

## 2. 전치사 / 접속사
#### 시간 표현
1. by / until
	- **by** → ~까지 완료
	- **until** → ~까지 계속
```
finish by 5 → 5시까지 끝내다
wait until 5 → 5시까지 기다리다
```
